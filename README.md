# 🐍 Python – Entrada de Dados e Operações Matemáticas

Este repositório reúne exercícios desenvolvidos no **Google Colab** com foco na prática dos conceitos fundamentais da linguagem **Python**, especialmente a interação com o usuário por meio da função `input()`, manipulação de variáveis e realização de operações matemáticas.

As atividades foram elaboradas para desenvolver o raciocínio lógico e reforçar os conhecimentos básicos da programação, utilizando exemplos práticos e aplicações simples.

---

## 🎯 Objetivos do Projeto

* Praticar a entrada de dados pelo usuário.
* Trabalhar com variáveis e tipos de dados.
* Desenvolver programas utilizando operadores aritméticos.
* Aprender a converter dados utilizando `int()`.
* Desenvolver a lógica de programação através de exercícios práticos.

---

## 📚 Atividades Desenvolvidas

### 🔹 Exercício Inicial – Entrada de Dados

Programa que solicita o nome do usuário utilizando a função `input()` e exibe a informação na tela.

**Conceitos praticados:**

* Entrada de dados (`input`)
* Variáveis
* Saída de dados (`print`)

---

### 🔹 Atividade 1 – Soma de Dois Valores

Programa que recebe dois números inteiros informados pelo usuário e calcula a soma entre eles.

**Conceitos praticados:**

* Entrada de dados
* Conversão de tipos (`int`)
* Operadores aritméticos
* Variáveis

---

### 🔹 Atividade 2 – Subtração de Valores

Programa que solicita dois números e realiza a operação de subtração, exibindo o resultado.

**Conceitos praticados:**

* Operadores matemáticos
* Entrada de dados
* Processamento de informações

---

### 🔹 Atividade 3 – Calculadora Básica

Desenvolvimento de uma calculadora capaz de realizar as quatro operações matemáticas fundamentais:

* Soma
* Subtração
* Multiplicação
* Divisão

Os resultados são apresentados de forma organizada ao usuário.

**Conceitos praticados:**

* Operadores aritméticos
* Variáveis
* Conversão de dados
* Entrada e saída de informações

---

### 🔹 Atividade 4 – Saudação ao Usuário

Programa que solicita o nome do usuário e exibe uma mensagem personalizada de boas-vindas.

**Conceitos praticados:**

* Entrada de dados (`input`)
* Manipulação de strings
* Personalização da saída de dados
